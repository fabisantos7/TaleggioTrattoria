Conhecendo
o Bootstrap.

Esta página explica como o framework mais popular de CSS do mundo sustenta o site da Trattoria Taleggio — do sistema de grid até o modal que confirma a sua reserva. Todos os exemplos abaixo são vivos: redimensione a janela e teste cada um.

(01)O que é?

Um kit de construção para a web

O Bootstrap é um framework front-end de código aberto criado em 2011 pelos engenheiros do Twitter (Mark Otto e Jacob Thornton). Ele reúne CSS e JavaScript prontos e testados — botões, formulários, menus, modais e um sistema de layout — que o desenvolvedor reutiliza em vez de escrever tudo do zero.

É a biblioteca mais popular do mundo nessa categoria: segundo a documentação oficial, atende cerca de 22% de todos os sites da internet.

No nosso projeto, o Bootstrap sustenta toda a estrutura: layout, navegação, formulário de reserva e as interações da página.

(02)Para que serve?

Problemas que ele resolve

Sem um framework, cada site precisaria reinventar a roda: escrever CSS para alinhar colunas, testar em dezenas de tamanhos de tela e criar do zero coisas complexas como menus suspensos e janelas modais. O Bootstrap resolve isso entregando:

  • Velocidade de desenvolvimento — componentes prontos que funcionam assim que a classe é aplicada;
  • Responsividade garantida — o grid se adapta sozinho a celular, tablet e desktop;
  • Consistência visual — espaçamentos, tipografia e cores padronizados;
  • Compatibilidade entre navegadores — as diferenças de cada navegador já foram tratadas;
  • Interatividade sem escrever JavaScript — modais, dropdowns e toasts funcionam só com atributos data-bs-*.

Resultado prático: o modal de confirmação da reserva abriu e fechou com zero linhas de JavaScript — apenas atributos HTML.

(03)Sistema de grid

A página é uma grade de 12 colunas

O coração do Bootstrap é o grid: a largura da página é dividida em 12 colunas, e montamos o layout combinando três peças:

1container

Envolve todo o conteúdo e centraliza a página com largura máxima.

2row

Cria uma linha horizontal. Só pode existir dentro de um container.

3col

As colunas ocupam a linha. O total soma até 12 por linha.

(04)Responsividade

Um site, infinitas telas

Design responsivo é a técnica de fazer uma única página se reorganizar conforme o tamanho da tela — sem versões separadas para celular e computador. O Bootstrap consegue isso com media queries prontas, agrupadas em cinco breakpoints que dão nome às classes: col-sm-*, col-md-*, col-lg-* e col-xl-*.

Teste aqui: redimensione a janela do navegador e veja o exemplo abaixo mudar na hora.

(05)Componentes

Os componentes deste projeto

Cada componente abaixo é usado no site da Taleggio — com função explicada e demonstração funcional. Clique e teste.

Grid (container · row · col)

Função: organizar todo o conteúdo em linhas e 12 colunas, com alinhamento perfeito em qualquer tela.

No projeto: base de todas as seções (hero, menú, reservas…).

Navbar + Collapse

Função: barra de navegação fixa que, em telas pequenas, esconde os links atrás de um menu recolhível.

No projeto: o botão ☰ no celular abre o menu de links.

✅ Este bloco foi aberto pelo componente Collapse.

Dropdown

Função: menu suspenso que revela opções ao ser clicado, com posicionamento automático.

No projeto: o botão de três pontos ao lado de "Reservar mesa".

  • Opção de exemplomenu suspenso do Bootstrap
  • Segunda opçãomesmo componente do site

Modal

Função: janela de diálogo sobre a página, com fundo bloqueado — ideal para confirmações.

No projeto: confirma a reserva com data, pessoas e código.

Toast

Função: notificação leve que aparece por alguns segundos e some sozinha.

No projeto: o aviso "Telefone copiado — a nonna agradece."

Form controls + Cards

Função: os form controls padronizam inputs e selects; os cards organizam informações em blocos visuais.

No projeto: formulário de reserva e cards dos "I Classici".
